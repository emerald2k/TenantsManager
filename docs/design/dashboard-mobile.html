Varianta pentru telefon — aceleași date, altă mecanică. Nu e ecranul de desktop micșorat: bara laterală neagră devine bară de file jos, la degetul mare; tabelul devine fișe; graficul se trage lateral, iar valorile apar la atingere, fiindcă pe telefon nu există „trecere cu mouse-ul". Ramele de mai jos se pot derula cu rotița, exact ca telefonul real. Cea de-a treia ramă arată sertarul „Mai multe" deschis, iar ultima este un ecran mic (iPhone SE / Android compact), ca să vezi că nimic nu se rupe.

Temă deschisă — de sus în jos Titlul, luna, apoi cifra care contează. Sub ea, restul în ordinea în care ai nevoie de ele. Clopoțelul cu bulină ține notificările; bara de file ține navigarea.
Temă închisă — lista lunii și graficul Aceeași pagină, derulată până la fișele chiriașilor. Fiecare fișă are numele sus, starea la mijloc, banii jos — și se apasă întreagă.
Sertarul „Mai multe" Bara de jos are cinci file — atât încap fără să devină imposibil de nimerit. Restul (proprietăți, notificări, limbă, temă, ieșire) stă într-un sertar care urcă de jos.
Ecran mic — 320 px Cel mai îngust telefon aflat încă în uz. Cifrele rămân întregi, butoanele rămân peste 44 px, nimic nu iese în lateral.

Fiecare schimbare rezolvă o problemă care apare doar pe telefon.

Bara laterală → bară de file josSus, în colțul stâng, degetul mare nu ajunge. Jos ajunge fără să muți mâna. Rămâne închisă la culoare, ca bara laterală pe care ai aprobat-o.
Șase secțiuni → cinci file + sertarPeste cinci file, fiecare devine prea îngustă ca s-o nimerești sigur. Notificările urcă în clopoțelul din titlu, unde bulina roșie se vede oricum.
Tabel → fișeȘapte coloane nu încap pe 390 px, iar derularea laterală într-un tabel ascunde tocmai coloana cu banii. Fișa pune numele, starea și suma una sub alta.
Grafic care se trage cu degetulDouăsprezece luni pe 390 px ar da bare de 8 px. Se trag lateral, se opresc pe lună, iar valoarea apare scris sub grafic — nu într-un balon care dispare.
Fără hover, doar apăsarePe telefon efectul de hover se lipește de ultimul element atins. Aici totul reacționează la apăsare: se afundă puțin și se colorează, apoi revine.
Ținte de minimum 44 pxFiecare rând, buton și filă are cel puțin 44–56 px înălțime. Săgeata „›" rămâne vizibilă permanent, fiindcă aici nu există alt indiciu.
